# Quratulain Shakeel — Business & Technology Portfolio

A responsive, accessible static portfolio centered on Gul Bakes, with education, courses, technical projects, participation records, and skills.

## Publish on GitHub Pages

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then click **Save**.
4. Wait for GitHub to finish deployment; the Pages settings will show the live URL.

Expected URL after deployment: https://tubaannie025-web.github.io/quratulain-business-portfolio/

## Editing

All styling, content, and small interactions are in `index.html`. No dependencies or build step are required. Open the file locally to preview it. The footer's print button supports saving a PDF through the browser.

Content distinguishes ongoing courses, participation, and proposed projects. The Gul Bakes sales milestone is self-reported. No unsupported awards, job titles, contact details, or credential IDs are included. Review and redact certificate images before adding them. Update course status and links when they change.

No analytics, trackers, form submissions, or third-party scripts are included.
